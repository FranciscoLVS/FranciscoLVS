# Hi, I'm Francisco!

I'm a Computer Engineering graduate from the University of Minho, interested in Software Engineering, Artificial Intelligence and Large Language Models (LLMs).

During my degree, I worked on projects involving distributed systems, computer networks, concurrent programming and web development. I enjoy understanding how things work and putting what I learn into practice through different projects.

## Projects

* **[InsideAirbnb Analytics](https://github.com/FranciscoLVS/insideairbnb-analytics)** — A web application for analysing accommodation data through interactive dashboards, maps and statistical tools. Built with Vue.js and JavaScript, using the Google Maps API for geospatial visualisation.

* **[Space Mission Communication System](https://github.com/FranciscoLVS/CC-SistemaComunicao-Rover-Nave)** — A network simulation project focused on communication between a mothership, rovers and a control station. I worked on UDP communication, data flow control and packet loss detection, using the CORE emulator to test network resilience.

* **[Distributed Time-Series System](https://github.com/FranciscoLVS/SD-SistemaSeriesTemporais)** — A concurrent client-server system developed in Java for managing time-series data. The project involved communication protocols, synchronisation, multiple simultaneous users and data persistence.

* **[SO-CLIENTSERVER](https://github.com/FranciscoLVS/SO-CLIENTSERVER)** — A document indexing and search service developed in C on Linux, using FIFOs for inter-process communication, parallel search and caching.
